# About the event 

「⽜津郡飯聚系列」係由 Oxford Hongkongers CIC 主辦的定期社群聚會，旨在為本地港⼈提供⼀個輕鬆、無壓⼒的交 流平台。無論你係新到埗，定係已經喺⽜津⽣活咗⼀段時間，都可以透過飯聚認識新朋友、分享⽣活點滴、互相⽀持。 我哋會輪流喺⽜津唔同地區舉辦飯聚，包括 Oxford 、 Abingdon 、 Bicester 等，形式以⾃由聊天、分享資訊為主。有時 仲會加插主題⼩活動，例如⽣活⼩貼⼠、港⼈故事分享、地區交流等。 呢個系列特別適合： 想識朋友、搵連繫的你 想放鬆下、食個飯嘅你 希望每⼀次飯聚都能成為你⽣活中的⼀點連結、⼀種熟悉的港式溫度💛
